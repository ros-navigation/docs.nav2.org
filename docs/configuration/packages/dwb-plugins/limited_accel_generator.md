# LimitedAccelGenerator

`<dwb plugin>`: DWB plugin name defined in the **controller_plugin_ids** parameter in [Controller Server](../configuring-controller-server.md#controller-server).

## Parameters

* **`<dwb plugin>`.sim_time:**
  | Type   |   Default |
  |--------|-----------|
  | double |       1.7 |
    
    Description
    : Time to simulate ahead by (s).
