# XYTheta Iterator

## Parameters

`<dwb plugin>`: DWB plugin name defined in the **controller_plugin_ids** parameter in [Controller Server](../configuring-controller-server.md#configuring-controller-server).

* **`<dwb plugin>`.vx_samples:**
  | Type   |   Default |
  |--------|-----------|
  | int    |        20 |

  Description
  : Number of velocity samples in the X velocity direction.
* **`<dwb plugin>`.vy_samples:**
  | Type   |   Default |
  |--------|-----------|
  | int    |         5 |

  Description
  : Number of velocity samples in the Y velocity direction.
* **`<dwb plugin>`.vtheta_samples:**
  | Type   |   Default |
  |--------|-----------|
  | int    |        20 |

  Description
  : Number of velocity samples in the angular directions.
